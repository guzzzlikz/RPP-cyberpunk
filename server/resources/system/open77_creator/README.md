# open77_creator

A complete character creator drawn over the live game (NativeUI), on the runtime body API
(`Open77.body.catalog/compose/decompose/active/switch`). Freeroam uses it so that new players
spawn in the world and build their character there instead of in the vanilla main-menu creator.

Guide: https://open2077.net/docs/runtime-character-creation

## Use

- `open77_appearance_creation "runtime"` (convar), or
  `exports.open77_appearance:setCreationMode("runtime")` from the gamemode at start.
- `dependency "open77_creator >=1.0.0"` in the gamemode manifest.
- A gamemode that places joining players: `exports.open77_creator:expectPlacement(true)` once,
  then `exports.open77_creator:playerPlaced(playerId)` when its join spawn has landed.

## API

Server exports: `open(playerId)`, `expectPlacement(on)`, `playerPlaced(playerId)`.
Client local event: `open77_creator:visibility` (`true` open / `false` closed) for HUDs.
Convars: `open77_creator_open_new` ("true"), `open77_creator_command` ("creator"),
`open77_creator_debug` ("false"; `creatordebug <action> [a] [b]` drives the UI for tests).
Table: `open77_creator_looks` (user, character, body type, choices JSON).

## Look and motion

The interface is a holographic workbench around the character: chamfered frames, slanted buttons,
a sliding selection on the tabs and the body type, options that arrive one after the other, values
that flick when they change, and the game's own UI sounds on hover and press.

- **Camera** (`CreatorConfig.camera`): the shot of a category is reached by a travelling, not a
  cut: eased, with a swing around the character and a pull back in the middle. The wheel zooms and
  a drag over the character turns and pans, both with inertia; Q / E turn; a slow sway keeps the
  shot alive. The opening is a move in from further back.
- **Depth** (`CreatorConfig.depth`): the panels are tilted toward the player, float slowly, and the
  whole interface leans after the mouse and against the camera's turn (`ui:projection`). Set
  `tilt`, `float` and `parallax` to 0 for a flat interface.
- **Starting looks** (`CreatorConfig.looks`): a picture per preset, `ui/looks/<file>.png`
  (354 x 396). A preset without a picture shows its initial.
- **Effects** (`client/effects.lua`): `cc-frame`, `cc-skew` and `cc-stripes` are registered with
  `Open77.ui.registerEffect` and used from `ui/creator.rcss` as `decorator: fx(...)`.
  `python tools/check_effects.py <open77-base checkout>` compiles them outside the game.

Two things worth knowing when you restyle it: the `x` / `y` motion channels are physical pixels
(move things that must line up with the layout with `top` / `left` and a `dp` value), and an
animated `opacity` on a child is not hidden by its parent's `opacity: 0`.

## Files

- `shared/config.lua`: categories (the game's uiSlots per tab), camera shots and travelling, depth,
  starting look pictures, sounds.
- `shared/locale.lua`: every UI text, English only; choice names derived from internal names.
- `shared/thumbs.lua`: generated by `tools/generate_thumbs.py` (option -> thumbnails).
- `client/effects.lua`: the GPU surfaces of the interface.
- `ui/creator.rml`, `ui/creator.rcss`, `ui/thumbs/*.png`, `ui/looks/*.png`: the interface.

## Thumbnails

`tools/generate_thumbs.py` cuts the game's character creation atlas into `ui/thumbs/*.png` and
writes `shared/thumbs.lua`. Inputs: `tools/icon-parts.tsv` (OptionsIcons record -> atlas part,
read from TweakDB), the exported atlas PNG and JSON, and the `.inkcharcustomization` JSON of both
body types. Run it with a Python that has Pillow after a game update changes the creator.
