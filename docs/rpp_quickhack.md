# Сканер и квикхаки — `rpp_quickhack`

Штатный `open77_quickhack` (Open77 77.248) поставляется выключенным. Наш ресурс
`server/resources/rpp_quickhack/` объявляет его зависимостью, и сервер запускает его сам.
Выключить: убрать `"rpp_quickhack"` из `resources.load` в `server.jsonc`
(и `server.host.jsonc`) и перезапустить сервер.

## Управление

| Клавиша | Действие |
|---|---|
| **TAB** (держать) | Сканер |
| Навести прицел | Захватить цель, через ~0,5 с — её данные |
| **Колесо мыши / ↑ ↓** | Выбрать скрипт |
| **F** | Загрузить скрипт в цель |
| **1 / 3** | Предыдущая / следующая цель |
| **Z** | Вкладки ДАННЫЕ / ВЗЛОМ |
| **H** | Справка |

Клавиши переназначаются в настройках клавиш Open77. У каждого игрока кибердека
на 19 ОЗУ (восстанавливается 0,6 в секунду), дальность сканера 60 м.
Настройки по умолчанию: `system/open77_quickhack/shared/config.lua`.

## Что сейчас работает

Только штатные примеры «Пинг»: они показывают карточку того, что сервер знает о цели.

| Цель | Что покажет |
|---|---|
| Машина (своя, `/car`, прокат) | Модель, здоровье, скорость, замок, пассажиров |
| Другой игрок | Имя, ID, позицию. Взломанный видит предупреждение о загрузке скрипта |
| Серверный NPC (боты PvP, NPC ресурсов) | Запись, владельца, здоровье |

Прохожие и припаркованный трафик — не цели: у них нет сетевого ID.

**Внимание:** «Пинг» на игроке показывает **ник аккаунта**, а не паспорт. Это обходит
анонимность `rpp_identity`. Для теста нормально, для игры примеры лучше выключить
(`examples = false` в `open77_quickhack/shared/config.lua`) и сделать свои квикхаки
в этом ресурсе.
