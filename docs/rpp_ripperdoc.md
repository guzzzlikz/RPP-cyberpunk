# Риппердок (rpp_ripperdoc)

Профессия: игрок-риппердок ставит и снимает импланты другим игрокам.

## Как стать риппердоком

Роль выдаёт администратор (ACL `command.rpp.ripperdoc`, у роли `admin` есть `command.*`):

```text
rpp.ripperdoc <ID игрока|me> on     сделать риппердоком
rpp.ripperdoc <ID игрока|me> off    снять роль
```

Роль запоминается за аккаунтом (kvp сервера) и сохраняется между заходами.

## Операция

1. **Пациент даёт согласие:** ALT на риппердоке (до 3 м) → **«Разрешить операцию»**.
   Согласие действует 2 минуты (`consentSec`). Без него сервер не даст ничего поставить
   или снять.
2. **Риппердок:** ALT на пациенте → **«Импланты (риппердок)»**. Открывается панель:
   - слева — что установлено (руки, ноги) и кнопка **«Снять»**;
   - справа — импланты для установки: из инвентаря пациента и из инвентаря риппердока,
     кнопка **«Установить»**.
3. **Снять:** имплант уходит **в инвентарь пациента**, с которого сняли. Если у пациента
   нет места, снять не дадут.
4. **Установить:** только в свободный слот (сначала снимите старый). Имплант списывается
   из выбранного инвентаря; если установка сорвётся, он возвращается обратно.

Операцию можно делать только рядом с пациентом (`distance`, 3 м) и по одной за раз.
Каждая операция пишется в консоль сервера.

## Импланты

Open77 сейчас поддерживает импланты двух зон:

| Зона | Имплант | Грейды (id предмета `cw_<зона>_<грейд>`) |
|---|---|---|
| Руки | Руки гориллы | `training`, `industrial`, `cosmetic`, стили банд: `aldecaldos`, `barghest`, `jinguji`, `militech`, `mox`, `tsunami`, `tyger_claws`, `voodoo_boys`, `wraiths`, `kang_tao` |
| Ноги | Усиленные ноги (двойной прыжок) | `training`, `athlete` |

Импланты — обычные предметы инвентаря (2×2, вид «Киберимплант»): их можно передавать
обменом, выбрасывать, выдавать админом: `rpp.item.give <ID> cw_arms_industrial`.

Определения имплантов ресурс объявляет сам (`rpp.gorilla`, `rpp.double_jump`, грейды как
у кибер-лаборатории). Имплант, поставленный не риппердоком (например, лабораторией),
при снятии превращается в предмет того же грейда, а если такого грейда нет — в
тренировочный.

## Что изменено вокруг

- `open77_cyberware_lab/server/freeroam.lua`: выключена автоматическая бесплатная выдача
  всем игрокам ног «athlete», рывка и рефлексов (`RPP_FREE_LOADOUT = false`): иначе
  снятые риппердоком ноги возвращались через секунду. Двойной прыжок теперь только у тех,
  кому его поставил риппердок.
- Панель самой кибер-лаборатории (`/cyberlab`) по-прежнему может ставить импланты в обход
  риппердока — это инструмент разработчика; для RP её стоит закрыть правами или убрать
  `open77_cyberware_lab` из `server.jsonc`.
- `rpp_inventory`: импланты-предметы, экспорт `listItems`, русские названия во вкладке
  «Импланты».
