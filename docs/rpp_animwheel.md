# Колесо анимаций (rpp_animwheel)

Ресурс `server/resources/rpp_animwheel`. Открывается клавишей **U** (переназначается в
настройках клавиш Open77, пункт «Колесо анимаций»), закрывается **U** или **Esc**.

## Колесо

- 12 слотов под анимации, которыми пользуетесь чаще всего.
- **Клик** по слоту — проиграть анимацию (окно закрывается).
- **ПКМ** по слоту — убрать анимацию из слота.
- **Центр («СТОП»)** — остановить текущую анимацию.
- Новая анимация сама останавливает предыдущую.

## Список анимаций

Кнопка **«Список анимаций»** рядом с колесом открывает все анимации сервера (из
`open77_animations`) с поиском и фильтром по категориям.

- **Двойной клик** по анимации — проиграть её (окно остаётся открытым).
- **Зажать и перетащить** на свободный слот колеса — закрепить. На занятый слот —
  заменить. Зелёная подсветка — свободный слот, жёлтая — замена.
- Анимации, уже стоящие в колесе, помечены «В КОЛЕСЕ».
- Подсказка про двойной клик и перетаскивание — внизу панели.

## Хранение

Набор слотов сохраняется на компьютере игрока (`Open77.kvp` клиента, ключ
`rpp.animwheel.slots`) и восстанавливается при следующем заходе. На другом ПК колесо
будет пустым.

Жесты из категории «В движении» с пометкой «один раз» проигрываются один раз, остальные
анимации — до остановки (центр колеса, движение или `/anim stop`).
