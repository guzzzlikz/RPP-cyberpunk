# Музыка при заходе (rpp_music)

Ресурс `server/resources/rpp_music` играет трек, пока игра загружает мир, и плавно
затихает через несколько секунд после появления персонажа.

## Как поставить свой трек

1. Сконвертируйте трек в `.ogg` (встроенный браузер игры надёжно играет `.ogg`,
   `.opus`, `.webm`; MP3 и M4A может не воспроизвести):
   ```
   ffmpeg -i track.mp3 -c:a libvorbis -q:a 5 join.ogg
   ```
2. Положите файл в `server/resources/rpp_music/web/music/join.ogg`.
3. Закоммитьте и запушьте: файл должен оказаться на ПК, где запущен сервер, игроки
   скачают его вместе с ресурсами.
4. Перезапустите сервер и переподключитесь.

Используйте музыку, на которую у вас есть права.

## Настройки (`config.lua`)

| Поле | Что делает |
|---|---|
| `tracks` | список файлов в `web/music/`; при каждом заходе выбирается случайный |
| `volume` | громкость 0..1 |
| `loop` | повторять трек, пока грузится мир |
| `fadeInMs`, `fadeOutMs` | плавное нарастание и затихание |
| `stopAfterWorldReadySec` | через сколько секунд после появления персонажа затихать; `0` — сразу, `-1` — доиграть трек до конца |
| `skipIfAlreadyInWorld` | не играть, если ресурс запустился, когда игрок уже в мире |

## Игроку

- Громкость — ползунок «Громкость веб-звука» в меню паузы (общий для всех веб-окон).
- `/music` — выключить музыку при заходе и запомнить выбор; ещё раз — включить.

## Как это устроено

Невидимое WebUI-окно с `<audio>` (звук веб-окон Open77 поддерживает официально, им же
пользуются телевизоры). Если трек не найден или формат не поддерживается, в клиентский
лог пишется `[rpp_music] track failed: ...`.
