# Тема интерфейса: жёлтый на чёрном, кириллица

Штатный интерфейс Open77 был циановым (`#22d8e2`) на тёмно-синем. На сервере он
перекрашен в жёлтый (`#fcee0a`) на нейтральном чёрном, и в нём исправлена кириллица.
Всё сделано в файлах ресурсов `server/resources`, клиенту ничего ставить не нужно:
игроки получают изменения при подключении.

## Кириллица

Встроенные в Open77 шрифты (Rajdhani, Chakra Petch, Lato) не содержат русских букв,
поэтому в чате, контекстном меню и над головами русский текст был пустым.

| Где | Как исправлено |
|---|---|
| Чат, контекстное меню, HUD, пауза (окна RmlUi) | `open77_chat` загружает шрифт **Play Bold** (`ui/fonts/Play-Bold.ttf`, лицензия OFL) как запасной: буквы, которых нет в основном шрифте, берутся из него. Запасной шрифт общий для всех RmlUi-окон |
| Подписи над головами | `open77_nameplates` переключает стиль табличек на шрифт `condensed` (системный Bahnschrift Condensed, кириллица есть) |
| Окна на WebUI (уведомления, админка, паспорт) | Кириллица работала и раньше: браузер берёт системные шрифты Windows |

`text-transform: uppercase` в RmlUi не переводит русские буквы в заглавные. Это
косметика, текст при этом читается.

## Цвета

- Стили (`.rcss`, `.css`, `.rml`, `.html`) перекрашены скриптом
  [`tools/recolor_ui.py`](../tools/recolor_ui.py) по оттенку:
  - циан → жёлтый с той же яркостью;
  - синеватые фоны и серые → нейтральные чёрные и серые;
  - янтарные предупреждения → оранжевые, чтобы не сливались с жёлтым;
  - красный (ошибка, урон) и зелёный (успех) не тронуты.
- Общий стиль RmlUi `nui://open77/open77.rcss` вшит в `Open77.dll`, его не поменять.
  Поэтому рядом с каждым RmlUi-окном лежит перекрашенная копия `ui/open77-yellow.rcss`,
  и окна подключают её вместо встроенной.
- Акценты, заданные в коде (`#22D8E2`, `#18D6E7`, `#00E5FF`, `{0,229,255}`,
  `{34,216,226}` в `.lua`/`.js`), заменены на `#FCEE0A`.

## HP-бар

HUD режима freeroam (`gamemodes/freeroam/ui/hud.rml` и `hud.rcss`, блок `#vitals`):

- жёлтая плашка с количеством HP;
- строка `// BIOMONITOR  SYS.OK ... 87 / 100`;
- полоса из 20 ячеек с уголками-скобками, красным следом полученного урона и бегущей
  линией сканера;
- снизу выносливость (оранжевая) и шкала-линейка;
- ниже 25 % HP всё краснеет, появляется мигающее `CRITICAL`.

## После обновления Open77

Обновление может вернуть штатные файлы ресурсов. Тогда снова перекрасьте стили (запуск
из `server/resources`):

```
python tools/recolor_ui.py --table <файлы>   # показать, что поменяется
python tools/recolor_ui.py --apply <файлы>   # перекрасить
```

Изменения в шрифтах, `open77-yellow.rcss`, HP-баре и акцентах в коде верните из git.
