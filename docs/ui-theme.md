# Тема интерфейса: жёлтый на чёрном, кириллица

Штатный интерфейс Open77 был циановым (`#22d8e2`) на тёмно-синем. На сервере он
перекрашен в жёлтый (`#fcee0a`) на нейтральном чёрном, и в нём исправлена кириллица.
Всё сделано в файлах ресурсов `server/resources`, клиенту ничего ставить не нужно:
игроки получают изменения при подключении.

## Кириллица

Встроенные в Open77 шрифты (Rajdhani, Chakra Petch, Lato) не содержат русских букв,
поэтому в чате, контекстном меню и над головами русский текст был пустым.

| Где | Как исправлено |
|---|---|
| Чат, контекстное меню, HUD, пауза (окна RmlUi) | `open77_chat` загружает шрифт **Play Bold** (`ui/fonts/Play-Bold.ttf`, лицензия OFL) как запасной: буквы, которых нет в основном шрифте, берутся из него. Запасной шрифт общий для всех RmlUi-окон |
| Подписи над головами | Встроенный рисовальщик табличек (C++ в `Open77.dll`) не умеет кириллицу ни с одним шрифтом: проверено, `style({font="condensed"})` не помог. Поэтому `open77_nameplates/client/main.lua` рисует таблички через WebUI-страницу (`RPP_WEB_NAMEPLATES = true`), где работают шрифты Windows. Минус: при резком повороте камеры табличка немного отстаёт. `false` возвращает встроенную отрисовку (только латиница) |
| Подсказки взаимодействия («Подобрать», «Открыть гонки», сцены) | `open77_interactions` рисовал их нативной «карточкой» шрифтом `Open77.dll` без кириллицы. Теперь их рисует WebUI-страница (`RPP_NATIVE_CARD = false` в `open77_interactions/client/main.lua`). Минус тот же, что у табличек: при резком повороте камеры подсказка немного отстаёт |
| Окна на WebUI (уведомления, админка, паспорт) | Кириллица работала и раньше: браузер берёт системные шрифты Windows |

`text-transform: uppercase` в RmlUi не переводит русские буквы в заглавные. Это
косметика, текст при этом читается.

## Цвета

- Стили (`.rcss`, `.css`, `.rml`, `.html`) перекрашены скриптом
  [`tools/recolor_ui.py`](../tools/recolor_ui.py) по оттенку:
  - циан → жёлтый с той же яркостью;
  - синеватые фоны и серые → нейтральные чёрные и серые;
  - янтарные предупреждения → оранжевые, чтобы не сливались с жёлтым;
  - красный (ошибка, урон) и зелёный (успех) не тронуты.
- Общий стиль RmlUi `nui://open77/open77.rcss` вшит в `Open77.dll`, его не поменять.
  Поэтому рядом с каждым RmlUi-окном лежит перекрашенная копия `ui/open77-yellow.rcss`,
  и окна подключают её вместо встроенной.
- Акценты, заданные в коде (`#22D8E2`, `#18D6E7`, `#00E5FF`, `{0,229,255}`,
  `{34,216,226}` в `.lua`/`.js`), заменены на `#FCEE0A`.

## HP-бар

HUD режима freeroam (`gamemodes/freeroam/ui/hud.rml` и `hud.rcss`, блок `#vitals`):

- жёлтая плашка с количеством HP;
- строка `// BIOMONITOR  SYS.OK ... 87 / 100`;
- полоса из 20 ячеек с уголками-скобками, красным следом полученного урона и бегущей
  линией сканера;
- снизу выносливость (оранжевая) и шкала-линейка;
- ниже 25 % HP всё краснеет, появляется мигающее `CRITICAL`.

## Русский язык

Интерфейс мода переведён на русский. Словари лежат в `tools/i18n/*.json`
(английский текст → русский), применяются двумя скриптами:

- `tools/translate_ui.py` — текст в `.rml` / `.html` (только текстовые узлы и
  `placeholder` / `title` / `aria-label`; теги, id, классы, `{{привязки}}` не трогаются);
- `tools/translate_code.py` — строки в `.js` / `.lua`. В JS — только фразы из двух и
  более слов, в Lua — только то, что уходит игроку (уведомления, чат, ответы команд,
  `label` / `title` / `message` / `help` и т. п.), без записей в лог.

Меню паузы переведено целиком в `open77_pause/shared/strings.lua`.

Отдельно вручную переведены подсказки на метках и событиях: чекпоинты гонок на карте
(«Чекпоинт 3/12», «Круг 1/3», «Финиш»), уведомления гонок и редактора трасс,
подсказки сцен («Использовать», «Нажмите H, чтобы встать», отказы), запасная подпись
подсказки open77_interactions («Действие») и названия клавиш карты и гонок.

Повторная проверка (поиск английского текста по всем ресурсам) добавила:

- ответы меню `/freeroam` и его команд (`/car`, `/dv`, `/goto`, `/tpc`, `/spawn`,
  `/suicide`, `/revive`, `/players`), веб-меню freeroam (гараж, оружие, перемещение, ТВ);
- окно гонок и редактора трасс (статусы очереди и старта, ошибки сохранения),
  команды `race.join` / `race.leave` / `race.editor`;
- карту города: легенда, слои, справка по управлению, поиск, GPS-подсказки
  («НАЛЕВО», «Вы прибыли») — через `page.locale` в `op77_map3d/shared/config.lua`,
  а подписи, зашитые в сборку, прямо в `web/assets/index-*.js`;
- ошибки команд в чате, подсказки контекстного меню, паузу (микрофон, устройство),
  гардероб, предложение обмена между игроками, ошибки загрузки персонажа,
  сообщения на экране телевизора, экран подключения при ошибке загрузки ресурсов;
- ответы команд `rpp_inventory` и `rpp_identity`.

Переведено: чат, HUD, таблица игроков, спидометр, контекстное меню, пауза, экран
подключения, меню `/freeroam` (транспорт, оружие, перемещение, персонаж, анимации,
телевизоры, гонки, PvP), гардероб, кибер-лаборатория, уведомления, подсказки
команд, внутриигровая админ-панель.

Не переведено:

- названия оружия, машин и брендов (они так и называются в игре);
- админские инструменты: нативное меню `open77_admin/client/menu.lua`, ответы
  серверной части админки и консольные команды `vehicle.*`, `elevator.*`,
  `weather.*`, `prop.*`, `effect.*`, `tv.*`, диагностика PvP (`dm.*`);
- описания настроек для Warden (`pvp/shared/config.lua`, `open77_nameplates` и др.);
- демонстрационные точки карты по умолчанию (если их не заменил свой список меток);
- инструменты разработчика: редактор камер (`open77_remote_camera`), полизоны,
  трафик, описания настроек для Warden;
- Warden (веб-панель сервера) — встроена в `Open77.Server.dll`;
- первый экран до подключения к серверу — он берётся из клиента мода, не с сервера;
- названия настроек самой игры в меню паузы — они идут на языке интерфейса игры.

Поиск анимаций по-прежнему по английским тегам (`smoke`, `dance`, `handsup`).

## После обновления Open77

Обновление может вернуть штатные файлы ресурсов. Тогда снова перекрасьте стили (запуск
из `server/resources`):

```
python tools/recolor_ui.py --table <файлы>   # показать, что поменяется
python tools/recolor_ui.py --apply <файлы>   # перекрасить
```

Изменения в шрифтах, `open77-yellow.rcss`, HP-баре и акцентах в коде верните из git.
